# Conexa

O **Conexa** é uma rede social moderna e responsiva hospedada na Vercel, projetada para conectar pessoas através de compartilhamento de publicações, comunidades de nicho, chat em tempo real e perfis personalizados.

## 🚀 Como começar

* Acesse a versão online: [https://conexa-lac.vercel.app](https://conexa-lac.vercel.app)
* Se for rodar localmente, instale as dependências com `npm install` e rode `npm run dev`.

## 📋 Funcionalidades

* **Feed Dinâmico e Comunidades:** Crie publicações, interaja com o conteúdo de outros usuários e filtre por comunidades específicas.
* **Chat em Tempo Real:** Converse diretamente com outros perfis através de mensagens instantâneas integradas via Supabase.
* **Perfis Personalizados:** Gerencie seu perfil, altere seu nome de usuário e personalize seus dados na plataforma.
* **Assuntos em Alta (Trending Topics):** Acompanhe as hashtags mais comentadas do momento.

## 🛠️ Tecnologias

* **React / React Native Web:** Interface modular para web e mobile utilizando componentes reutilizáveis.
* **TypeScript:** Tipagem estática para maior segurança e escalabilidade do código.
* **Supabase:** Autenticação de usuários e banco de dados em tempo real.
* **Tailwind CSS & Vite:** Estilização moderna e empacotamento ultrarrápido para produção.
* **Vercel:** Hospedagem e deploy contínuo automatizado.
